# MCP 設定（レッスン6）

`mcp.json` に、このプロジェクトの開発で使う外部 MCP サーバーを登録している。

## fetch

- **パッケージ**: `mcp-server-fetch`（`uvx` で起動）
- **用途**: Web 上の URL からコンテンツを取得する。
- **このプロジェクトでの狙い**: 開発中に外部ドキュメントやリリースノートを Kiro から直接参照する。

## aws-docs

- **パッケージ**: `awslabs.aws-documentation-mcp-server`（`uvx` で起動）
- **用途**: AWS 公式ドキュメントを検索・参照する。
- **このプロジェクトでの狙い**: 「AWS 資格学習プランナー」というテーマ上、登録する資格や学習トピック
  （例: VPC, IAM, S3 など）の正確な情報を AWS 公式ドキュメントから確認できるようにする。

## 前提

- `uvx`（および `uv`）のインストールが必要。
  インストールガイド: https://docs.astral.sh/uv/getting-started/installation/
- MCP サーバーはサードパーティのツールであり、別途の利用規約が適用される場合がある。
  信頼できるソースのみを登録すること。
