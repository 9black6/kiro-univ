# 要件定義（Requirements）

## 概要

AWS 認定資格の学習計画と進捗を管理する Web アプリ「AWS 資格 学習プランナー」の要件を定義する。
ユーザーは受験予定の資格を登録し、試験日から逆算して学習トピックを管理し、進捗を可視化できる。
データはブラウザの localStorage に保存し、サーバーや DB を必要としない。

要件は EARS（Easy Approach to Requirements Syntax）記法で記述する。

---

## 用語

- **資格 (Certification)**: 受験対象の AWS 認定資格。名前と試験予定日を持つ。
- **トピック (Topic)**: 資格に紐づく学習単位（分野）。完了/未完了の状態を持つ。
- **進捗率 (Progress)**: ある資格に属するトピックのうち、完了済みの割合。

---

## 要件 1: 資格の登録・管理

**ユーザーストーリー:** 受験者として、受験予定の資格と試験日を登録したい。試験日から逆算して計画を立てられるようにするため。

### 受け入れ基準

1. WHEN ユーザーが資格名と試験予定日を入力して追加操作を行う THE SYSTEM SHALL 新しい資格を一覧に追加する
2. IF 資格名が空である THEN THE SYSTEM SHALL 資格を追加せず、入力欄付近にバリデーションエラーを表示する
3. WHEN ユーザーが資格の削除操作を行う THE SYSTEM SHALL その資格と、紐づく全トピックを削除する
4. THE SYSTEM SHALL 登録済みの資格を一覧として常に表示する

## 要件 2: 試験日までの残り日数

**ユーザーストーリー:** 受験者として、試験日までの残り日数を知りたい。学習ペースを把握するため。

### 受け入れ基準

1. WHEN 資格に試験予定日が設定されている THE SYSTEM SHALL 本日から試験日までの残り日数を計算して表示する
2. IF 試験日が本日より過去である THEN THE SYSTEM SHALL 「期限切れ」を表す表示を行う
3. IF 試験日が本日と同じである THEN THE SYSTEM SHALL 残り日数を 0 日として表示する

## 要件 3: 学習トピックの管理

**ユーザーストーリー:** 受験者として、資格ごとに学習トピックを追加・完了・削除したい。学習範囲を分解して進めるため。

### 受け入れ基準

1. WHEN ユーザーが特定の資格にトピック名を入力して追加操作を行う THE SYSTEM SHALL そのトピックを当該資格に追加する
2. IF トピック名が空である THEN THE SYSTEM SHALL トピックを追加しない
3. WHEN ユーザーがトピックの完了トグルを操作する THE SYSTEM SHALL そのトピックの完了状態を反転する
4. WHEN ユーザーがトピックの削除操作を行う THE SYSTEM SHALL そのトピックを一覧から削除する

## 要件 4: 進捗の可視化

**ユーザーストーリー:** 受験者として、資格ごとの進捗率を一目で把握したい。達成度を確認してモチベーションを保つため。

### 受け入れ基準

1. THE SYSTEM SHALL 各資格について、完了済みトピック数 ÷ 全トピック数 を百分率で表示する
2. IF 資格にトピックが 1 件も存在しない THEN THE SYSTEM SHALL 進捗率を 0% として表示する
3. THE SYSTEM SHALL 進捗率をプログレスバーなどの視覚的要素で表現する

## 要件 5: 学習ペースの提案

**ユーザーストーリー:** 受験者として、試験日まで 1 日あたり何トピック進めればよいか知りたい。無理のない計画を立てるため。

### 受け入れ基準

1. WHEN 資格に未完了トピックと未来の試験日が存在する THE SYSTEM SHALL 「未完了トピック数 ÷ 残り日数」を 1 日あたりの推奨トピック数として表示する
2. IF 残り日数が 0 以下である THEN THE SYSTEM SHALL ペース提案の代わりに注意表示を行う

## 要件 6: データの永続化

**ユーザーストーリー:** 受験者として、入力した内容が次回も残っていてほしい。毎回入力し直さずに済むため。

### 受け入れ基準

1. WHEN データ（資格・トピック）が変更される THE SYSTEM SHALL 変更後の状態を localStorage に保存する
2. WHEN アプリが起動する THE SYSTEM SHALL localStorage から保存済みデータを読み込んで復元する
3. IF localStorage に保存データが存在しない THEN THE SYSTEM SHALL 空の初期状態で起動する
