# プロダクト概要

## 何を作るか

「AWS 資格 学習プランナー」は、AWS 認定資格の学習計画と進捗を管理する Web アプリ。
受験予定の資格と試験日を登録し、学習トピックを分解して進捗を可視化する。試験日までの残り日数と、
1 日あたりの推奨学習ペースを提示する。

## 対象ユーザー

AWS 認定資格の受験を予定している学習者。1 人で使うことを前提とする。

## 設計の原則

- **ローカル完結**: サーバーや DB を持たず、データは localStorage に保存する。インストール不要でブラウザだけで動く。
- **シンプルさ優先**: 機能を盛り込みすぎず、資格・トピック・進捗の 3 概念に絞る。
- **ロジックと UI の分離**: 日数・進捗・ペースの計算は純粋関数に切り出し、テスト可能にする。

## やらないこと（スコープ外）

- ユーザー認証、複数ユーザー、クラウド同期
- 問題演習や学習コンテンツそのものの提供
- 通知・リマインダー機能
